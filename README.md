# 코인 차트 분석기 (with 근거)

업비트·바이낸스의 **공개 시세**를 읽어 차트를 그리고, 그 차트를 왜 그렇게 읽었는지 **근거 리포트**를 함께 만들어주는 단일 HTML 페이지입니다.

**바로 열기 → https://kim-dukjoong.github.io/coin-chart-analyzer/**

## 무엇을 보여주나

**왼쪽 — 차트**
캔들 + 이동평균선(MA20·60·120) + 거래량, 그 아래 RSI(14)와 MACD(12,26,9). 세 패널의 시간축이 함께 움직입니다. 프로그램이 찾아낸 지지·저항은 점선으로 표시됩니다.

**오른쪽 — 근거 리포트 (자동 생성)**

1. **시장 맥락** — BTC 일봉 추세를 먼저 판정. BTC가 하락 구조면 개별 코인의 상승 시나리오 신뢰도를 낮춰 보라고 명시합니다.
2. **멀티 타임프레임 추세** — 주봉·일봉·4시간봉을 각각 판정하고 가중치 3 : 2 : 1로 종합합니다. 판정 근거는 이동평균선 배열과 고점·저점 구조(HH·HL / LH·LL)를 실제 가격과 함께 적습니다.
3. **핵심 가격대** — 가격이 여러 번 방향을 바꾼 지점(피벗)을 군집으로 묶어 지지·저항을 특정하고, 몇 번 지켜진 가격인지와 이동평균선 중첩 여부를 근거로 답니다.
4. **보조지표 교차 검증** — RSI 구간, MACD 골든/데드크로스 발생 시점, 거래량의 20봉 평균 대비 배수. 가격과 RSI가 엇갈리는 **다이버전스**도 자동으로 잡아냅니다.
5. **시나리오** — 상승·하락·횡보를 각각 `트리거 → 목표 → 무효화 라인` 형식으로 제시합니다. 무효화 라인은 "이 판단이 틀렸다고 인정하는 가격"입니다.
6. **손익비(R:R)** — 현재가 진입을 가정해 계산하고, 1:1.5 미만이면 매력 없는 자리라고 표시합니다.

## 사용법

주소를 열고 상단에서 고르기만 하면 됩니다. 설치도, 회원가입도, API 키도 필요 없습니다.

- **거래소**: 업비트(원화 275개) / 바이낸스(USDT 671개) 전환
- **종목**: 업비트는 `이더리움`·`ETH`·`KRW-ETH`, 바이낸스는 `SOL`·`SOL/USDT` 모두 인식
- **기간**: 주봉 / 일봉 / 4시간 / 1시간 / 15분

내려받아서 `index.html`을 더블클릭해도 똑같이 동작합니다(크롬 권장 — 사파리는 로컬 파일의 외부 요청을 기본 차단합니다).

### ⚠ 업비트는 웹에서 분당 6회 제한

업비트 API는 **웹사이트 주소에서 오는 요청**에 분당 6회라는 별도의 좁은 할당량을 적용합니다(`remaining-req: group=origin; min=6`). 그래서 이 주소로 접속하면 업비트 조회가 자주 실패합니다. 게다가 업비트는 429 응답에 CORS 헤더를 붙이지 않아서, 브라우저에는 원인 불명의 네트워크 오류로 보입니다.

- **바이낸스는 제한이 없습니다** — 그래서 웹으로 열면 바이낸스가 기본 거래소로 선택됩니다.
- **파일을 내려받아 더블클릭하면 업비트도 제한이 풀립니다.** `file://`과 `localhost`는 분당 600회 할당량(`group=candles`)을 받기 때문입니다.

이 페이지는 요청을 한 줄로 세워 간격을 두고 보내고, 일봉 캔들에 들어 있는 전일 종가를 재활용해 시세 요청을 한 번 줄입니다.

## 만들어진 방식

파일 하나에 전부 들어 있습니다. 빌드 도구도, 서버도, 백엔드도 없습니다.

- 시세: [업비트 공개 API](https://docs.upbit.com/) / [바이낸스 공개 API](https://binance-docs.github.io/apidocs/spot/en/) — 인증 불필요
- 차트: [TradingView Lightweight Charts](https://github.com/tradingview/lightweight-charts) v4.2.3 (Apache License 2.0, 파일에 인라인 포함)
- 지표(SMA·EMA·RSI·MACD)와 피벗 군집 계산은 직접 구현했습니다

**서버가 없다는 건 곧 기록도 없다는 뜻입니다.** 페이지를 연 사람의 브라우저가 거래소에 직접 시세를 요청하고 그 자리에서 계산합니다. 누가 어떤 코인을 조회했는지 수집·저장하는 곳이 없고, 보유 수량이나 매수가를 입력하는 기능 자체가 없습니다.

## ⚠️ 고지

이 페이지는 기술적 분석 **교육·참고 자료**이며, 특정 종목의 매수·매도 권유나 투자 자문이 아닙니다. 제작자는 공인 투자자문업자가 아닙니다.

프로그램의 판정은 **규칙 기반 계산**입니다. 이동평균선 배열이나 고점·저점처럼 기계가 셀 수 있는 것만 봅니다. 뉴스, 수급, 시장 심리, 차트 패턴의 맥락은 반영되지 않습니다. 계산에 오류가 있을 수 있습니다.

**모든 투자 판단과 그 결과에 대한 책임은 이용자 본인에게 있습니다.**
